# AMB82 Mini 手勢控制電燈系統

## 專案介紹

使用 AMB82 Mini 與攝影機辨識手勢，透過 GWS S35 STD 連續旋轉伺服馬達，機械撥動一個既有的電燈開關。辨識、判定與馬達控制都在板端執行；同一 Wi-Fi 上的手機或電腦可用瀏覽器查看攝影機畫面、操作區（ROI）及控制狀態，並啟用或停用辨識。

## 材料

| 材料 | 數量與用途 |
| --- | --- |
| AMB82 Mini 與相容攝影機 | 1 組，負責取像、手勢辨識及控制 |
| GWS S35 STD 連續旋轉伺服馬達 | 1 顆，用於撥動開關 |
| 伺服臂、撥桿與固定支架 | 1 組，固定馬達並傳遞動作 |
| 杜邦線、USB 資料線 | 各 1 組，用於接線、板子供電與燒錄 |
| 電燈開關 | 1 個，由撥桿機械操作 |

辨識提示使用 AMB82 Mini 的板載藍色 LED，不需外接 LED。

## 接線

| 端點 | 接法 |
| --- | --- |
| 伺服馬達訊號線 | AMB82 Mini `D8`（`PF_15`） |
| 伺服馬達 V+ | AMB82 Mini 板上的電源腳 |
| 伺服馬達 GND | AMB82 Mini 板上的 `GND` 腳 |
| AMB82 Mini USB | 接電腦，供電及燒錄 |


## SDK 版本

- 開發環境：Arduino IDE。
- 板卡套件：Realtek **AmebaPro2 4.1.0**。
- 開發板：**AmebaPro2 ARM (32-bits) Boards → AMB82-MINI**。

## 模型

使用自訂五類手勢 **YOLOv7 Tiny** 模型。`GestureLight/yolov7_tiny.nb` 是已轉換的模型檔，程式以 `CUSTOMIZED_YOLOV7TINY` 載入，不需要重新訓練。

| 手勢 | Class ID | 用途 |
| --- | --- | --- |
| 5 | 4 | 開燈 |
| 1 | 0 | 關燈 |
| 2、3、4 | 1、2、3 | 不觸發控制 |

攝影機影像為 **576 × 320**，JPEG 預覽目標為 **20 FPS**，模型影像輸入設定為 **10 FPS**。模型只接收裁切後的 ROI（X：116–460；Y：48–272）；有效辨識框須完整落在區內。網頁只顯示開燈與關燈類別。

## 燒錄方式

1. 使用 USB 資料線連接板子。在 Arduino IDE 開啟 `GestureLight/GestureLight.ino`，讓 `.ino`、所需 `.h` 檔及 `yolov7_tiny.nb` 保持在同一個 `GestureLight` 資料夾。
2. 在 `GestureLight/Config.h` 填入 Wi-Fi 名稱及密碼。選擇 `AMB82-MINI`、實際相機型號及板子對應的序列埠，將 **Load NN Model from** 設為 **Flash**。
3. 讓板子進入下載模式：按住 `UART_DOWNLOAD`，按一下並放開 `RESET`，再放開 `UART_DOWNLOAD`。在 Arduino IDE 點選「上傳」。
4. 上傳成功後按一下 `RESET` 正常開機。將序列監控視窗設為 **115200 baud**，從 `Monitor: http://…` 取得板子的網址。

## 操作方式

1. 將手機或電腦連到和板子相同的 Wi-Fi，在瀏覽器開啟序列埠顯示的 `http://` 網址。序列埠只輸出訊息，操作不需要輸入指令。
2. 開機預設啟用辨識；相機、推論與 Wi-Fi 就緒時，系統可接受手勢。先移開手掌，讓 ROI 清空至少 **0.5 秒**。
3. 將單一手勢完整放在 ROI 內，維持至少 **500 ms**。手勢須達 **60%** 信心門檻。手勢 **5 開燈**、手勢 **1 關燈**；馬達沿對應方向轉動 **400 ms** 後停止，不回程。有效判定時板載藍燈亮 **1 秒**。
4. 下一次操作前，將手移出 ROI 至少 **0.5 秒**，並等候 **2 秒**冷卻。開／關指令須交替；重複手勢會顯示已經開燈或關燈的提示，藍燈仍會亮，但馬達不動。首次開機可先做任一指定手勢。
5. 按網頁的「**停用辨識**」可停止手勢控制與馬達動作，攝影機預覽仍可觀看。按「**啟用辨識**」後先清空 ROI，再做手勢。重新開機會恢復預設啟用。
